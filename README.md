# Flowriter 用戶手冊

所見即所得的 Markdown 桌面編輯器（Electron + React + Milkdown / ProseMirror），玻璃質感介面，檔案永遠是標準 Markdown。
前身為 Inkwell；為了讓你的設定與歷史版本不會消失，程式沿用舊的使用者資料夾，內部的 `inkwell://` 圖片協議與資料鍵名也沒有更動。

> 目前版本：0.4.x。回饋信箱：kaikai122148@163.com（「說明 → 關於」可一鍵寫信）。

## 一、快速開始

1. 安裝並開啟 Flowriter。第一次啟動會有歡迎畫面；更新後第一次啟動會顯示「更新了什麼」。
2. 直接打字：Markdown 標記只在游標所在的區塊顯示，離開就渲染成排版後的樣子。
3. 儲存：`Ctrl/⌘ + S`。已有檔案時可開自動儲存（見「設定 → 寫作」）。
4. 找不到功能？按 `Ctrl/⌘ + Shift + P` 開命令面板，輸入關鍵字；所有命令也都能在上方選單列找到。

### 三種檢視

| 模式 | 切換 | 說明 |
| --- | --- | --- |
| 所見即所得 | 預設 | 邊寫邊排版 |
| 源碼 | `Ctrl/⌘ + /` | 純 Markdown 文字（CodeMirror），支援多游標（Alt+點擊、Ctrl/⌘+D、矩形選取） |
| 源碼＋預覽 | 源碼模式內切換 | 左右分欄，分隔線可拖曳（雙擊還原），兩側捲動同步，可左右互換 |

### 多分頁與文件樹

- 分頁列在功能區下方：`+` 新建、`×` 或中鍵關閉，未儲存的分頁有圓點。把分頁拖出分頁列可變成新視窗。
- 同一檔案重複開啟只會切到既有分頁；關閉全部分頁後會留一個空白文件。
- 側欄可顯示資料夾文件樹（新建、重命名、移到回收桶、在檔案管理器顯示），搜尋結果可點擊跳到命中位置並高亮。
- 文件樹可「開啟 / 關閉 / 更換資料夾」，也可合併多個資料夾的文件樹。

### Markdown 語法

- 標準 Markdown、表格（插入時可用格數選擇器）、任務列表、腳註（`[^1]`，滑過顯示內容）、YAML front matter（顯示成資料卡，存檔原樣寫回）、`[TOC]` 目錄。
- 擴充語法：`==高亮==` 等行內標記、雙反引號行內代碼；`{{price * 1.5}}` 行內算式（結果只顯示在畫面上，不寫進檔案）；`:::bilingual` 雙語對照。
- 提示框（callout）：`> [!NOTE]` 一系列類型（提醒／警告／重點／備註／總結／引言…），選取文字後可直接轉成提示框。
- 公式（LaTeX）、Mermaid 流程圖（在代碼塊下方即時預覽，預覽不會寫進 `.md`）。流程圖可「隱藏代碼 / 隱藏圖表」二選一。
- 代碼塊：語法高亮，行號可分別在所見即所得、源碼、代碼塊中開關。

### 樂譜

在代碼塊的語言標籤填入下列之一即會在下方畫出樂譜：`abc`（五線譜）、`jianpu`（簡譜）、`gongche`（工尺譜）、`tab`（六線譜）、`mei` / `xml`（MEI、MusicXML）、`lilypond`。

- 游標進入樂譜圍欄時會出現專屬工具列（譜號、調號、拍號、連音線等）。
- 每塊樂譜都有播放控制：播放／暫停、停止、可拖曳的進度條和狀態文字；播放時正在響的音符會在譜面和代碼上高亮。
- 樂譜可隱藏代碼或隱藏譜面（二選一）；可複製為透明 PNG。
- 播放用簡單的合成音，不是真實樂器採樣。LilyPond 的播放來自程式自己對常見語法的解析，複雜寫法可能與排版結果不同；六線譜與 LilyPond 播放時沒有譜面高亮。

### 代碼塊執行器

JavaScript、Python 可在隔離環境執行；C、C++、Rust、Java、Go、Ruby、PHP、Perl、Lua 由主程序呼叫本機編譯器／直譯器執行。結果只顯示在代碼塊下方的唯讀區，**絕不寫回 `.md`**；3 秒強制中止，危險用法需二次確認。

## 三、整理與檢查

- **大綱**：側欄大綱可拖曳標題，整個章節（含子標題）一起移動。
- **章節進度尺**：編輯區頂部細進度線，標題位置為圓點，滑過會顯示標題，點擊跳轉。
- **文件健檢**：標題跳級、腳註缺漏、失效連結／錨點、不存在的本機圖片、未完成待辦等。
- **排版檢驗**：中英文空格、全半形標點、重複標點、括號引號配對，可一鍵修正；另有「AI 檢查」分頁。
- **文風診斷**、**段落權重**、**朗讀校對**、**任務收集**、**表格排序**。
- **頁邊便條**：選取文字後寫便條，引文後出現 ✎ 圖示，滑過時高亮引文；便條存在文件旁的 `.inkwell` 資料夾。
- **段落上鎖**：被鎖的段落無法被改動。
- **文件比對**：整頁比對兩份文件，兩側都可直接編輯、選取、複製。
- **連結與反向連結**：`[[筆記名]]` 連結、`Ctrl/⌘ + 點擊` 開啟（不存在則詢問後建立）；面板列出反向連結與二跳關係。
- **連結關係圖**（檢視選單 / 連結面板 / 命令面板）：掃描資料夾，畫出筆記與連結的力導向圖，可看「本文周邊」（1–3 層）或「全部筆記」，點節點開啟，虛線空心點＝尚未建立的筆記（點一下建立）。

## 四、歷史、備份與資料安全

- **版本時光機**：每次手動儲存與間隔足夠的自動儲存都留快照，可預覽、段落回滾、垃圾桶（找回刪掉的段落）、里程碑、章節演進、「那年今天」。自動儲存間隔可調，並與時光機快照同步。
- **崩潰恢復**：有未儲存更改時每幾秒寫入本機工作狀態，異常結束後下次啟動自動恢復。
- **加密**：筆記旁檔（便條、參考、語音、上鎖資訊）以 AES-256-GCM 加密存放，金鑰檔在本機使用者資料夾內；加密抽屜密碼不保存，**忘記無法找回**。
- **使用者資料備份 / 還原 / 清除快取**：「設定 → 資料與維護」。備份檔為 `.flowbak`，包含設定與旁檔。
- **發佈到 Git**（檔案選單 / 命令面板）：初始化倉庫、設定 `origin`、拉取（僅快轉）、提交並推送；預設只提交文件與圖片。GitHub、Gitee、GitLab、自架皆可。

## 五、匯出、列印與圖床

- **匯出 HTML / PDF、列印**：開啟設定對話框，左邊調參數、右邊即時預覽。可調：紙張（A3/A4/A5/Letter/Legal）、橫向、四邊邊距、字體、主題（淺色／米黃／深色）、字級、行高、加入目錄、PDF 頁首標題與頁碼、保留背景色、自訂 CSS；設定會記住。
- 其他匯出：Word、長圖 PNG、輪播圖、Markdown。
- **圖床**（「設定 → 圖片與圖床」）：貼上或拖入圖片時可存到文件旁 `assets`、PicGo / PicList，或自訂 HTTP 圖床；上傳失敗自動改存本機。命令「上傳本文的本地圖片到圖床」可批次轉換整篇。

## 六、專注、氛圍與工具

- **番茄鐘**：預設停靠在右側欄，可切換成可拖曳的浮動小窗（選擇會被記住）；多組預設、自訂時長、每輪目標字數。
- **音樂庫**（氛圍音面板 → 音樂庫）：選音樂庫資料夾、匯入多種格式、掃描資料夾、播放清單（圖示或封面）、順序／列表循環／單曲循環／隨機、睡眠計時；播放時底欄有頻譜。環境音則提供合成或錄音版氛圍。
- **聚焦 / 打字機 / 閱讀模式 / 迷你置頂便籤**、寫作儀表盤（字數目標、連續天數）、接續提示（記住上次落筆位置）。

- **收件匣膠囊**：全域快捷鍵 `Ctrl/⌘ + Alt + Space`（需在設定開啟）。
- **設定**分成「介面與外觀 / 寫作與儲存 / 圖片與圖床 / AI 與自訂 / 語言 / 資料與維護 / 更新與關於」區塊；主題 25 組，可依時段自動換。

## 七、注意事項

**資料與安全**
- 檔案本身是標準 Markdown；筆記、上鎖等旁檔另放在文件旁的 `.inkwell` 資料夾。**搬動或同步文件時請把旁檔資料夾一起帶走。**
- 旁檔加密的金鑰在本機使用者資料夾裡：它能保護被複製、被雲端同步出去的資料夾，但**擋不住能登入你這台電腦的人**。
- 加密抽屜與備份檔的密碼不保存，忘記就無法找回。
- 圖床的標頭／金鑰只存在本機設定，不會寫進文件；但「備份」會包含本機設定，分享備份檔前請留意。
- 時間膠囊是依本機時鐘判斷的軟鎖，不是加密。

**行為與限制**
- 音樂庫預設資料夾在使用者資料目錄，程式更新不會動它；「移除」只是從清單拿掉，**不會刪你的音訊檔**。整個音訊檔會一次讀入記憶體播放，單檔上限 200 MB。音樂庫不包含在「資料備份」裡。
- 列印沒有頁首頁尾選項（系統列印接口不支援）；匯出預覽是連續畫面，實際輸出才分頁。Word 匯出：公式以原始碼文字呈現、Mermaid 不轉圖、樂譜以圖片呈現。
- Git 發佈需要電腦上已安裝 Git；登入由本機 git 憑證管理處理，程式不碰密碼；從不強制推送；提交時略過本倉庫的提交鉤子（`--no-verify`）。沒有衝突解決介面。
- 連結關係圖最多掃 3000 個 Markdown 檔，節點超過 800 時只顯示連結最多的部分；同名筆記會指向路徑較短的那一個。
- 版本快照只對已儲存為檔案的文件記錄；調整章節、還原版本會重建編輯器，該分頁的復原歷史會清空。
- 行內擴充標記（如 `==高亮==`）在編輯器裡標記符號仍可見（只是加了樣式）；Word 匯出不會轉換它們。
- 啟動後 DOM 翻譯只翻譯語言表中已有的字串；AI 提示詞本身仍為中文。
- Windows 毛玻璃需 11 22H2+；Windows 10 與 Linux 自動退回應用內玻璃。
- 安裝檔未簽署：Windows 會出現 SmartScreen 警告，macOS 首次開啟需手動放行。
- 本專案持續開發，新功能（樂譜播放、音樂庫、圖床、Git 發佈、關係圖等）剛加入，若遇到問題請附上操作步驟寄到回饋信箱。

## 八、開發者資訊

```bash
npm install
npm run dev        # 開發（固定綁 127.0.0.1:38417）
npm run build      # 建置
npm run dist       # 打包安裝檔（electron-builder，需在對應系統上建置）
npm test           # vitest 單元測試
npm run test:e2e   # Playwright 啟動 Electron 的冒煙測試（Linux 需 xvfb-run）
```

```
src/main        Electron 主進程：檔案系統、對話框、匯出／列印、音樂庫、Git、圖床、連結圖
src/preload     contextBridge 暴露的安全 API
src/shared      主進程與渲染進程共用型別與純函式
src/renderer/src
  editor/       MarkdownEditor（Milkdown Crepe）、plugins、樂譜 UI、SourceEditor（CodeMirror 6）
  components/   側欄、面板、匯出／Git／關係圖對話框、設定…
  lib/          命令註冊表、設定、i18n（locales/）、樂譜引擎（lib/music）、播放器
  export/       HTML / PDF / Word 匯出與匯出選項
  styles/       主題變數、玻璃材質、編輯器樣式
```

- 設計原則：不污染 `.md` 原始碼、編輯只走 ProseMirror transaction、儲存時維持標準 Markdown、重運算一律防抖。
- 發佈：把 `package.json` 的 `version` 調高，提交後推 `v版本號` 標籤，GitHub Actions 會在三個系統建置，更新來源是 GitHub Releases（`chankaikai/Flowriter`）。
- 在 Windows 若出現 `listen EACCES ... :5173`，開發伺服器已固定使用 `127.0.0.1:38417`。
- 開發時若看到 `Failed to fetch dynamically imported module …/App.tsx`，真正的錯誤是終端裡的第一條 `Pre-transform error`。
