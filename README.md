# Flowiter

> 前身為 Inkwell。為了讓你的設定與歷史版本不會消失，程式會繼續使用舊的使用者資料夾；內部的 `inkwell://` 圖片協議與資料鍵名也沒有更動。

所見即所得的 Markdown 桌面編輯器（Electron + React + Milkdown/ProseMirror）。

## 啟動

```bash
npm install
npm run dev        # 開發
npm run build      # 建置
npm run dist       # 打包安裝檔（electron-builder）
```

## 架構

```
src/main        Electron 主進程：檔案系統、對話框、PDF 匯出、inkwell:// 圖片協議
src/preload     contextBridge 暴露的安全 API
src/shared      主進程與渲染進程共用型別
src/renderer/src
  editor/       MarkdownEditor（Milkdown Crepe）、plugins（聚焦/打字機/查找）、SourceEditor（CodeMirror 6）
  components/   Sidebar、Palette、FindBar、SettingsPanel…
  lib/          commands（快捷鍵註冊表）、settings、markdown 工具、path
  export/       HTML / PDF / Word 匯出（獨立於編輯器，源碼模式也能用）
  styles/       theme.css（三套主題變數）、ui.css、editor.css
```

核心設計：單一文檔模型，Milkdown 在游標所在區塊顯示 Markdown 標記、離開即渲染。
源碼模式是獨立的 CodeMirror 視圖（支援多光標：Alt+點擊、Ctrl/⌘+D、矩形選取）。

## 液態玻璃 UI

- `lib/pill.ts`：玻璃膠囊（`usePill`）。切換時朝運動方向拉長 → 彈簧過衝回彈；邊緣有細高光。用於側欄頁籤、設定內分段控制、停靠欄。
- `components/GlassCard.tsx`：磨砂玻璃卡片。游標處徑向光斑、靠近游標的邊框局部提亮、3D 傾斜（≤4°，rAF 插值復原）、Border Beam 邊緣流光。
- `components/ExpandCard.tsx`：點擊按鈕後卡片原位放大成詳情（FLIP + portal），關閉時沿原路收回；Esc 先收詳情。
- `components/Dock.tsx`：底部居中浮動玻璃停靠欄，只放圖標；懸停高斯放大並帶動相鄰圖標，上方顯示名稱與快捷鍵；打字時自動淡出。
- 材質變數集中在 `styles/theme.css`（`--glass-*`、`--rim-*`、`--beam-*`），樣式在 `styles/glass.css`。

## 系統級毛玻璃

- macOS：`vibrancy: 'under-window'`（`visualEffectState: 'active'`，失焦也保持）。
- Windows 11 22H2+（build ≥ 22621）：`backgroundMaterial`，可在「設定 → 外觀」切換亞克力 / 雲母。
- Windows 10、Linux：不支援，自動退回應用內玻璃，設定中的開關會停用。
- 開啟後視窗透明，內容區以「內容區不透明度」鋪主題色保證可讀；主題切換時同步 `nativeTheme.themeSource`，讓材質明暗與 App 一致（跟隨系統時還原）。
- 已知：Windows 亞克力在拖動/縮放視窗時可能略有卡頓，這是系統層行為，可改用雲母。

## 多分頁

- 分頁列在標題欄，當前分頁以玻璃膠囊做底並滑動切換；`+` 新建、`×` 或中鍵關閉，未儲存的分頁顯示圓點。
- 快捷鍵：Mod+W 關閉、Mod+Alt+←/→ 切換、Mod+N 新建。
- 切換時各分頁保留內容與捲動位置；已有路徑且開啟自動儲存時，離開前會先寫入磁碟。
- 同一檔案重複開啟會切到既有分頁；目前是未改動的空白頁時原地替換，不多開分頁。
- 切換分頁會重建編輯器，所以各分頁的復原歷史不保留。

## 大文件效能

- 輸入時不再每次序列化整篇 Markdown：編輯器只發出「有變動」訊號（比對 doc 物件身分，O(1)），防抖後才同步內容並更新字數 / 大綱，延遲隨文件大小在 180ms～1.5s 之間自適應；自動儲存同理。
- 超過 `LARGE_DOC`（15 萬字元）的文件：先顯示載入提示再解析；內容超過約 10 萬字時對離屏區塊啟用 `content-visibility: auto`，瀏覽器跳過看不見區塊的版面與繪製。
- 查找：文件超過約 30 萬節點大小時，輸入期間只映射既有結果而不重掃全文。
- 大綱捲動追蹤改為二分搜尋。
- 取捨：`content-visibility` 會對區塊套用繪製隔離，極少數超出區塊邊界的裝飾（如表格把手）在超大文件中可能被裁切；捲動條長度在區塊第一次進入視野前是估算值。
- 這些都是結構性優化，沒有實測數據；若仍卡頓，請告訴我文件大小與卡頓的操作（輸入 / 捲動 / 開啟），我再針對性處理。

- 圖示：`build/icon.png`（1024×1024），electron-builder 會自動轉成 ico / icns。

- 安裝檔未簽署：Windows 會出現 SmartScreen 警告，macOS 首次開啟需手動放行；正式發佈需自備簽署憑證。
- `package.json` 的 `author` / `homepage` 是佔位值，發佈前請改成你自己的。

## 已知限制

- 第一次完整跑起來前我無法在沙盒內安裝依賴，所以未做過實機執行，只做了語法檢查與純邏輯測試。
- Crepe 的 `renderPreview`、`proxyDomURL` 等設定名稱依 7.x 文件撰寫；若版本差異導致 Mermaid 預覽或相對路徑圖片不顯示，改這兩處即可。
- Word 匯出：公式以原始碼文字呈現，圖片以替代文字呈現，Mermaid 不會轉圖。
- HTML/PDF 匯出的公式為 MathML（Chromium 原生渲染），Mermaid 會轉為內嵌 SVG，本機圖片會內嵌為 base64。

## 工作狀態與便利功能

- **工作階段還原**：關閉前保存分頁、目前分頁與捲動位置；未命名分頁連內容一起保存。下次啟動自動還原。
- **最近開啟**：`Ctrl/⌘ + Alt + O`，模糊搜尋最近 15 個檔案。
- **外部修改偵測**：視窗取得焦點時比對檔案修改時間。未修改的分頁靜默重新載入，有未儲存更改時先詢問。
- **貼上 HTML → Markdown**：從網頁、Word、Google 文件貼上時自動轉成乾淨的 Markdown（程式碼編輯器與原始碼模式內不轉換）。

## 編輯器內的 front matter、腳註、目錄

- **YAML front matter**：文件開頭的 `---` 區塊在編輯器中顯示成可編輯的資料卡，存檔時原樣寫回（不再被當成分隔線 / 標題）。命令面板 →「插入 YAML 前置資料」。
- **腳註**：`[^1]` 顯示為上標引用，`[^1]: 內容` 顯示為文末定義。輸入 `[^名稱]` 自動轉成引用；`Mod+Alt+F` 插入下一個編號並在文末建好定義；點引用跳到定義，點定義編號跳回。
- **`[TOC]`**：獨立一行的 `[TOC]` 變成會即時更新的目錄，點擊跳到章節。匯出 HTML / PDF 時同樣展開成目錄。命令面板 →「插入目錄」。
- **每個分頁獨立的撤銷歷史**：每個分頁保留自己的編輯器實例（最近用過的 5 個），切換分頁不再清空撤銷堆疊，也不必重新載入。第 6 個以後最久沒用的會被回收，其撤銷歷史隨之清除。
- **崩潰恢復**：有未儲存更改時每 5 秒把內容寫入本機工作狀態；異常結束後下次啟動自動恢復。若該檔案在這之後被其他程式改過，會提醒。正常關閉時你已選擇儲存或放棄，不會保留。

## 批次 B：擴展語法（進行中）

- **提示框** `> [!NOTE]` / TIP / WARNING / IMPORTANT / CAUTION / INFO / DANGER / SUCCESS / QUESTION：編輯器內顯示為玻璃卡片，檔案仍是標準 blockquote。（指令：插入提示框）
- **雙語對照** `:::bilingual` … `---` … `:::`：雙欄編輯，匯出 HTML 也是雙欄。（指令：插入雙語對照）
- **行內算式** `{{price * 1.5}}`，以 `@price = 10` 宣告變數；結果只顯示在畫面上（裝飾），不寫進檔案；匯出時才展開。
- **腳註懸浮預覽**：滑鼠移到腳註上顯示內容。
- **front matter 徽章**：文件開頭的 YAML 顯示為標籤；布林欄位可點擊切換（只改那一行，註解保留）。
- **任務收集**（Ctrl/Cmd+Alt+J）：列出未完成的 `- [ ]`，點擊跳到該行。
- **表格排序**：指令「表格依目前欄位升/降序排序」，數字欄位按數值排序，是可復原的 transaction。
- 尚未完成：Mermaid 點選跳行、LaTeX 複製為 PNG。

## 批次 C：歷史與安全

- **版本時光機分頁**：版本 / 段落回滾 / 垃圾桶 / 章節演進 / 那年今天。
- **里程碑**：指令「標記目前版本為里程碑」；有名字的版本不會被 200 份上限清掉。
- **段落回滾**：和舊版逐段比對，只把勾選的段落換回去。
- **垃圾桶**：歷史裡有、現在沒有的段落，可插回游標處。
- **章節演進**：某個章節在每次存檔時的字數變化與內容。
- **那年今天**：一週 / 一個月 / 三個月 / 半年 / 一年…前的快照卡片。
- **時間膠囊**（Ctrl/Cmd+Alt+V）：封存一段文字到指定時間才能開啟。這是依本機時鐘判斷的軟鎖，不是加密。
- **加密抽屜**：AES-256-GCM，密碼經 PBKDF2-SHA256 310000 次衍生；密碼不儲存，忘記無法找回。

## 開發疑難

- Windows 出現 `listen EACCES ... ::1:5173`：開發伺服器現在固定綁 `127.0.0.1:38417`。若仍被拒絕，用 `netsh interface ipv4 show excludedportrange protocol=tcp` 查系統保留的埠，改 `electron.vite.config.ts` 的 `port`。

## AI 額度與用量

- **本機模型**（localhost / 區域網路位址）：顯示「無帳戶額度」。
- **有公開餘額介面的服務商**：DeepSeek、Kimi（月之暗面）、SiliconFlow、OpenRouter 可直接「查詢帳戶餘額」。
- **其他服務商**（Claude、OpenAI、Qwen、智譜、Gemini、訊飛…）沒有公開的餘額介面，只能顯示「到控制台查看」的連結。
- **本機用量統計**：每次改寫後記錄輸入 / 輸出 tokens，顯示今日與累計（只存在這台電腦）。
- **回覆長度上限**：偏好設定可調（預設 4096），推理型模型建議調大。

## 批次 D（進行中）：寫作診斷與工具

- **文件健檢**（Ctrl/Cmd+Alt+K）：標題跳級／重複、腳註缺漏、空連結、失效的 `#錨點`、本機圖片不存在、TODO、算不出的 `{{算式}}`。匯出前會自動檢查，有「錯誤」等級時先問你。
- **排版檢查**：中英文空格、全半形標點、重複標點、括號引號配對；可一鍵修正（可在時光機還原）。程式碼、網址、front matter 不檢查。
- **文風診斷**：過長句子、「的」過多、連續三句同開頭、弱化詞、重複用詞（英文：長句、被動、副詞、贅詞）。只提示，不改文字。
- **段落權重**（Ctrl/Cmd+Alt+W）：左側色條越深表示段落越長。
- **朗讀校對**（Ctrl/Cmd+Alt+Y）：念選取處或從游標開始，念到哪句就選取哪句。用系統語音，沒有安裝中文語音時會提示失敗。
- **剪貼簿收集**（Ctrl/Cmd+Alt+B）：手動開啟後收進任何程式複製的文字（上限 30 則，只存記憶體）。
- 尚未完成：收件匣膠囊、片段縫合、知識雷達、關聯圖、並排參考抽屜、邊註、程式碼執行、反向大綱、讀者視角、語音片段、輪播圖匯出。

## 頁邊便條（批次 D #23）

選取一段文字後按 `Ctrl/⌘+Alt+N`（或「工具」選單／功能區）開啟面板，寫下便條。便條存在文件旁的 `.inkwell/notes.json`，**不會寫進 .md**；以原文引文做錨點，原文被改掉時標為「失聯」而不是消失。

## 二跳關係（批次 D #11）

「連結與反向連結」面板新增兩區：**與本文引用相同對象的筆記**（共同連到哪些 `[[…]]`），以及**經由反向連結再連出的筆記**。只讀必要檔案（最多 12 個連出對象、20 篇反向連結），純唯讀、不改任何檔案。

## 收件匣膠囊（批次 D #8）

設定 →「寫作」開啟全域快捷鍵後，在任何程式按 `Ctrl/⌘+Alt+Space` 會跳出一個小視窗：Enter 存入、Shift+Enter 換行、Esc 或點外面取消。內容以 `- [ ] 時間 內容` 追加到 `文件/Flowiter/Inbox.md`（只追加，不會改動既有內容）。也可從「檔案」選單選「快速收集到收件匣…」、「開啟收件匣檔案」。快捷鍵預設關閉；若被其他程式占用會提示。

## 片段縫合器（批次 D #9）

「剪貼簿收集」面板下方：勾選 2 則以上片段，選風格（連貫段落／條列／大綱），按「縫合」交給你設定的 AI 合成一段，再決定插入或捨棄。指令要求只用片段內已有資訊、不新增事實。**只有按下按鈕時，勾選的片段才會送到 AI 服務**（單則上限 3000 字、總計 12000 字，超過會提示）。

## 本地知識雷達（批次 D #10）

`Ctrl/⌘+Alt+G`（工具選單／功能區「知識雷達」）：以選取的文字（沒選取則用游標之後的段落）在目前資料夾內找相關筆記。自建 BM25 關鍵字索引（中文用雙字詞、英文用單字），最多 500 個 md/txt 檔、每檔前 200KB，只存記憶體，全程本機計算、不上傳；可手動重建索引，也可直接改上方查詢文字。結果會顯示最相關段落與命中的詞。

## 參考資料抽屜（批次 D #13）

`Ctrl/⌘+Alt+U`（工具選單／功能區「參考抽屜」）：每份文件各有一個抽屜，收「標題＋來源（網址或頁碼）＋內容」。選取文字後開啟會自動預填內容。可一鍵「插入為引用」（`>` 引用區塊，落款帶來源，網址會變成連結）。資料存在文件旁的 `.inkwell/refs.json`，不會寫進 `.md`；文件需先儲存。

## 代碼塊執行器（批次 D #32）

**直接在代碼塊上執行**：JavaScript、Python、C、C++、Rust、Java、Go、Ruby、PHP、Perl、Lua 的代碼塊右上角（「Copy」旁）會出現「▶ 執行」，點一下結果就顯示在代碼塊正下方（可複製輸出、清除、執行中可停止）。也可以把游標放進代碼塊按 `Ctrl/⌘+Alt+E`。不需要開面板。

安全設計（防呆與防破壞）：
- **JavaScript／Python** 在隔離環境（Worker／Pyodide）執行；**C／C++／Rust／Java／Go／Ruby／PHP／Perl／Lua** 由主程序呼叫你電腦上已安裝的編譯器／直譯器（gcc／g++／rustc／go／java／ruby／php／perl／lua），找不到會提示安裝。Shell、SQL、批次檔等一律不執行。
- 原生語言**沒有沙盒**：在一次性暫存資料夾執行（結束後刪除）、環境變數中的金鑰類被移除、編譯 20 秒／執行 5 秒逾時並殺掉整個程序樹、輸出上限 64KB，首次執行每個語言都會先確認。執行前會擋下明顯的刪檔／改檔、啟動其他程式、網路、系統呼叫、unsafe／內嵌組語等寫法（黑名單，無法保證擋住刻意繞過的程式，請只執行你信任的程式碼）。
- 在**一次性 Web Worker** 裡跑：沒有 DOM、沒有 Node、沒有檔案系統，碰不到文件、編輯器與程式本身；網路與儲存全域物件在執行前移除，移除失敗則**拒絕執行**（fail-closed）。
- Python 使用 Pyodide（WebAssembly）。**首次執行需從 cdn.jsdelivr.net 下載執行環境（約 10 MB），會先詢問你**；`import js`／`pyodide`／`micropip` 與 `__` 魔術屬性會被擋下。
- **3 秒強制中止**（Worker terminate；Python 另有 90 秒的載入逾時）、輸出最多 200 行／2 萬字、程式碼上限 2 萬字。
- 含網路／Node／無限迴圈等用法需**二次確認**。
- **結果只顯示在代碼塊下方的唯讀區，絕不寫回 `.md`**；修改代碼後舊結果自動消失。只在你按「執行」時才跑。

已知限制：記憶體無法精確限制；Python 的隔離依賴載入後移除全域物件；按鈕位置依 Crepe 代碼塊的「Copy」按鈕定位，找不到時會退回固定位置。
