# 簡譜語法說明（```jianpu）

在編輯器裡寫一個語言標記為 `jianpu` 的代碼塊，預覽就會渲染成簡譜。游標進入該代碼塊時，上方會出現工具列，可一鍵插入記號。譜面只在預覽中渲染，Markdown 原文保持純文字，不會被改動。

````markdown
```jianpu
1=C 4/4
func: T | S | D7 | T
1 3 5 | 6 1 4 | 5 7 2 | 1 - - |
(1 2 3) 5 | 6. 5 3 - |
```
````

## 1. 第一行：調與拍號（必填）

格式固定為 `1=<調> <拍號>`，必須是第一個非空行。

| 寫法 | 意思 |
| --- | --- |
| `1=C 4/4` | C 大調，四四拍 |
| `1=G 3/4` | G 大調，三四拍 |
| `1=F# 6/8` | 升 F |
| `1=Bb 2/4` | 降 B（也可寫 `1=bB`，會被規範成 Bb） |

調名為 A–G，可後接 `#` 或 `b`。拍號的分母必須是 2 的次方（2、4、8、16…），分子至少為 1。拍號只用於顯示，不會逐小節檢查拍數。

## 2. 音符

| 寫法 | 意思 |
| --- | --- |
| `1` … `7` | 唱名 do re mi fa sol la si |
| `0` | 休止符 |
| `1'` | 高八度（點在音符上方）；`1''` 高兩個八度 |
| `1,` | 低八度（點在音符下方）；`1,,` 低兩個八度 |
| `5.` | 附點（時值 ×1.5） |
| `-` | 延時線，單獨一個，前後要有空格 |

八度記號只能寫在數字後面。`'1` 這種寫法是錯誤，不會被悄悄接受。

## 3. 時值（減時線）

預設一個音符是一拍（四分音符）。

| 寫法 | 時值 | 譜面 |
| --- | --- | --- |
| `1` | 四分 | 無線 |
| `1/` 或 `1_` | 八分 | 底下一條線 |
| `1//` 或 `1__` | 十六分 | 底下兩條線 |

最多兩條減時線。相鄰的八分音符會共用一條線，十六分音符再加第二條。附點與減時線可組合，附點必須在前：`5./` 正確，`5/.` 會報「不認得的記號」。

## 4. 小節線

| 寫法 | 意思 |
| --- | --- |
| `\|` | 小節線 |
| `\|\|` | 雙小節線（段落） |
| `\|]` | 終止線（結尾） |

## 5. 連音線與連音符

- `( 1 2 3 )`：連音線，用弧線連起括號內的音。`(3 1 2 3)` 是連音線蓋住 3、1、2、3 四個音，不是三連音。
- `(3: 1 2 3)`：連音符（三連音），冒號是區別記號，譜面上方會畫括號並標數字 3。數字可換成其他數（如 `(5: …)`）。
- 括號必須成對。沒有關閉會報錯並指出開括號的位置。

## 6. 柱式和弦

用方括號把同時發聲的音包起來：`[1 3 5]`。音符由低到高疊放。和弦後面同樣可以接附點與減時線，八度記號寫在各音符後面：`[1 3 5']`。

## 7. 功能和聲標記（選用）

`func:` 這一行寫在旋律行的前面，內容按 `|` 拆成每個小節一個標記，顯示在那一小節的上方，並套用在緊接著的下一行旋律。

```jianpu
1=C 4/4
func: T | S | D7 | T
1 3 5 | 6 1 4 | 5 7 2 | 1 - - |
```

標記的數量與下一行的小節數不同時只會出現警告，譜仍會渲染。標記內容不限於 T/S/D，任何不含 `|` 的文字都可以，例如 `T`、`S`、`D7`、`Ⅵ`。

## 8. 多行與換行

每個非空行（除第一行與 `func:` 行）都是一行旋律。過長的行渲染時會自動換行。CRLF 與空行都能正確處理。

## 9. 錯誤提示

不認識的記號一律報錯，不會靜默丟掉。錯誤顯示在譜面下方一行紅字，包含行號與列號，例如：

- 第一行不是調號與拍號：「第一行必須是『1=<調> <拍號>』，例如 1=C 4/4」
- 拍號不合理，如 `1=C 4/7`
- 括號沒有關閉
- 出現無法辨認的字元

## 10. 工具列

游標在 `jianpu` 代碼塊裡時出現。有選區時作用在選取的音符，沒有選區時在游標處插入。

| 按鈕 | 行為 |
| --- | --- |
| 高八度／低八度 | 選中一個音符就加 `'` 或 `,`，否則插入 `1'` / `1,` |
| 附點 | 給選中的音符加 `.`，否則插入 `5.` |
| 八分／十六分 | 加 `/` 或 `//`，否則插入 `1/` / `1//` |
| 延時線 | 插入 `-` |
| 連音線 | 選區包上 `( )`，否則插入 `(1 2 3)` |
| 三連音 | 插入 `(3: 1 2 3)` |
| 功能標記 | 在第一行下方插入 `func: T`，已經有就不重複插 |

另有「隱藏代碼」按鈕，可以只留譜、收起代碼，不影響檔案內容。

## 11. 完整範例

```jianpu
1=C 4/4
func: T | S | D7 | T
1 3 5 | 6 1' 4 | 5 7 2' | 1' - - |
(1 2 3) 5 | 6. 5 3 - |
[1 3 5] [2 4 6] | 0 5/ 6/ 7 1' |]
```

## 12. 與標準 Markdown 的關係

`jianpu` 是一個普通的代碼塊語言標記，匯出為 Markdown 時就是標準的 fenced code，在其他編輯器中會被當作純文字代碼顯示，不會損壞。
