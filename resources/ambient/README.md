# 氛圍音錄音檔

把真實錄音放在這裡，檔名 = 種類，例如 `rain.ogg`、`ocean.mp3`、`fire.ogg`、`cafe.ogg`、`forest.ogg`、`stream.ogg`、`wind.ogg`、`night.ogg`、`fan.ogg`。
支援 ogg / mp3 / wav / m4a / flac / opus，建議 30 秒以上、可無縫循環，單檔不超過 60 MB。
沒有錄音檔的種類，會退回軟體合成的版本（比較單調）。

使用者也可以在「氛圍音」面板按「匯入錄音」自己加，不需要重新打包。

請只放你有權使用的檔案（例如 CC0 / 公有領域，Freesound、Pixabay 的 CC0 音效）。
